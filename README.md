# Room by Room

Адаптивный демонстрационный сайт ремонтной компании: интерактивная планировка квартиры, прайс, форма заявок и защищённый кабинет владельца. Сервер и база заявок работают в одном приложении.

## Требования

- Node.js 22.13 или новее (`node:sqlite` входит в Node.js).
- npm для установки Three.js.

## Запуск

```sh
npm install
npm start
```

Откройте `http://localhost:4173/`. Страница входа владельца: `/admin`. При первом старте случайный пароль создаётся и сохраняется во внешнем файле `owner.env` внутри каталога данных. Не добавляйте этот файл в Git и задайте собственный `ROOM_DATA_DIR` для постоянной установки.

## Настройки окружения

| Переменная | Назначение | Значение по умолчанию |
| --- | --- | --- |
| `PORT` | Порт веб-сервера | `4173` |
| `ROOM_DATA_DIR` | Каталог для базы данных и `owner.env` | `D:\\Codex\\Room-by-Room` на Windows; `./data` на других системах |
| `ROOM_NODE_MODULES` | Каталог, в котором установлен пакет `three` | `./node_modules` или `ROOM_DATA_DIR/node_modules` |
| `ROOM_ASSET_PATH` | Дополнительная GLB-модель | Путь к модели на Windows; `./assets/room.glb` на других системах |

Без GLB-файла интерактивная квартира отображается процедурной 3D-сценой. GLB добавляет внешнюю модель в сцену.

## Перед публикацией и запуском для клиентов

- Замените демонстрационные цены в кабинете владельца.
- Заполните реквизиты и контакты оператора в политике конфиденциальности и проверьте её для своей компании.
- Используйте HTTPS, настройте резервные копии базы и ограничьте доступ к каталогу данных.
- Не публикуйте `owner.env`, файлы базы (`*.sqlite*`) и реальные заявки.

Встроенный сервер подходит для локальной демонстрации и небольшой установки. Для публичного production-развёртывания используйте хостинг Node.js с HTTPS, секретами окружения, резервным копированием и мониторингом.
